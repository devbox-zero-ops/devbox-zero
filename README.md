# ⚡ DevBox Zero

**100% Local-First, Privacy-Focused Developer Toolkit** — runs completely in your browser with zero server uploads, zero cookies, and zero tracking.

## Features
- **JSON Formatter, Minifier & TypeScript Interface Generator**
- **Offline JWT Decoder** (inspect header, payload & `exp` timestamp locally)
- **UTF-8 Safe Base64 & URL Encoder / Decoder**
- **5-Field Cron Expression Explainer**
- **Line-by-Line Text Diff**
- **Cryptographic UUID v4 & 256-bit Hex Secret Generator** (Web Crypto API)

## Privacy Guarantee
Everything executes inside your local browser tab. No payload, token, or secret ever leaves your machine.
